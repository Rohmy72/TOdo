# 📝 ToDo App  

A cross-platform ToDo application built using **FlutterFlow** and **Firebase** that allows users to manage their daily tasks efficiently, track progress, and stay motivated with inspirational quotes.  

---

## 🚀 Overview  

The **ToDo App** provides users with the ability to:  
- Create accounts and log in securely using email/password authentication  
- Add, edit, and delete tasks  
- Mark tasks as completed and track progress  
- Update personal profile information  
- View a random **Zen Quote** each time the Tasks page loads for daily inspiration  

This project integrates **FlutterFlow UI**, **Firebase Authentication**, and a simple **Zen Quotes API**.  

---

## 🧩 Features  

- 🔐 **User Authentication** – Secure login and signup using Firebase  
- 🧠 **Persistent Task Storage** – Tasks and status are synced to Firebase  
- ✅ **Mark Tasks as Completed** – Visual tracking and persistence across sessions  
- 👤 **Profile Management** – Update name and profile picture  
- 💬 **Motivational Quotes** – Displays a new inspirational quote each time the Tasks page loads  
- 🌐 **Cross-Platform Compatibility** – Works on web and mobile

## 🧠 User Stories  

### 1. Create an Account  
**As a user**, I want to create an account using email/password authentication, so I can access my to-do list across devices.  

### 2. Log In  
**As a user**, I want to log in securely, so I can view and manage my existing to-do list.  

### 3. Add a Task  
**As a user**, I want to add new tasks, so I can organize what I need to get done.  

### 4. Edit or Delete a Task  
**As a user**, I want to modify or delete my tasks, so I can keep my list up to date.  

### 5. View All Tasks  
**As a user**, I want to see all my tasks in one list, so I can easily track progress.  

### 6. Inspirational Quotes  
**As a user**, I want to see a random inspirational quote each time I open the Tasks page, so I stay motivated.  

### 7. Update Profile  
**As a user**, I want to update my name and profile picture, so I can personalize my account.  

### 8. Mark Tasks as Completed  
**As a user**, I want to mark tasks as completed, so I can track my progress.
